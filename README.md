# Портфолио Олега Шпарбера

Витрина работ в стиле рабочего стола Windows 3.1/95: Program Manager с иконками проектов,
модальные окна, ASCII-портрет, скрепыш и честный синий экран смерти в качестве пасхалки.

**Живьём:** https://gigoctopus.ru/me/

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Вся витрина: CSS и JS в одном файле, без сборки и зависимостей |
| `visitka.html` | Макет визитки 90×50 мм, две стороны, с вылетами под обрез |
| `resume.html` | Резюме под hh и ATS |
| `mkpdf.js` | Playwright: `resume.html` → `assets/CV_Oleg_Sparber.pdf` |
| `mkvisitka.js` | Playwright: `visitka.html` → PDF (RGB и CMYK) и PNG для мессенджеров |
| `assets/` | Скриншоты, видеодемо (H.264), QR-коды, готовые PDF |

## Как обновить и выложить

```bash
sudo cp index.html visitka.html /srv/me/
sudo cp -r assets/* /srv/me/assets/
sudo chown -R caddy:caddy /srv/me
```

Пересборка PDF:

```bash
node mkpdf.js        # резюме
node mkvisitka.js    # визитка
```

Для `mkpdf.js` и `mkvisitka.js` нужен Playwright с локальным Chromium:

```bash
NODE_PATH=/path/to/node_modules node mkvisitka.js
```

## Принципы, по которым это сделано

- **Никаких выдуманных чисел.** Каждая цифра в карточках проверяема: 10 184 событий и 148 источников
  у СПРУТа, 2 103 предмета в каталоге марок. Что не подтверждается — в витрину не попадает.
- **Работа отделена от пет-проектов.** Две группы сетки: клиенты и продакшен против экспериментов.
  Пока шутки стоят в одном ряду с клиентскими работами, витрина читается как «делает что нравится».
- **Карточки рабочей группы — «что было / что стало».** Не список технологий, а боль владельца
  и её результат.
- **Видео только H.264** с флагом `+faststart`, без звука: HEVC не играет в Chromium на Linux.
- **Визитка проверяется на печати:** по 3 мм вылета с каждой стороны, окно отступает от линии реза,
  QR-коды декодируются с 300-dpi рендера CMYK.
- **Модалка блокирует фон:** прокрутка заперта на `html` и `body`, клик по затемнению её не закрывает,
  Tab циклится внутри, фокус возвращается на место после закрытия.

## Что не в репозитории

Исходники скриншотов (тяжёлые PNG) и служебные проверочные скрипты Playwright — они нужны
только на машине, где собирается сайт. Webp-версии, которые грузит браузер, лежат в `assets/`.
